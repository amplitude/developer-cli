# Contributing

This repository is the published distribution of the `amp` CLI
(`@amplitude/developer-cli`). It is maintained by Amplitude and updated through
an internal release process.

## We don't accept pull requests here

Changes are authored upstream and published to this repository, so external
pull requests can't be merged. PRs opened here will be closed with a pointer to
this guide — please don't take it personally.

## Found a bug or want a feature?

Please [open an issue](https://github.com/amplitude/developer-cli/issues). Good
reports include:

- The `amp` version (`amp --version`)
- The exact command you ran and what you expected
- The actual output or error (redact tokens and other secrets)

We triage issues, fix them upstream, and the change lands here on the next
release.

## Security

Do not file security reports as public issues. Follow the disclosure process in
[`SECURITY.md`](./SECURITY.md).
